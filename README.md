# Prácticas de Data Analytics — Coderhouse

Este repositorio reúne los ejercicios y proyectos que realizo durante el curso de Data Analytics de Coderhouse, utilizando SQL y Power BI.

El objetivo es aplicar los conceptos del curso para organizar datos, realizar consultas y transformar los resultados en información útil para el análisis de negocio.

## Contenido

- **Bases de datos:** diseño de tablas, definición de claves primarias y relaciones.
- **SQL:** creación y modificación de registros, filtros, agrupaciones y consultas para responder preguntas de negocio.
- **Análisis de datos:** cálculo de indicadores e identificación de hallazgos.
- **Power BI:** se incorporarán reportes y dashboards a medida que avance el curso.

## Herramientas

- SQL Server y SQL Server Management Studio (SSMS).
- Power BI Desktop.

## Consultas de negocio — Módulo 4

El archivo `m4_consultas_negocio.sql` contiene cuatro consultas:

1. Resumen mensual de facturación, cantidad de pedidos y ticket promedio.
2. Ranking de los cinco productos con mayor facturación.
3. Identificación de clientes con más de un pedido.
4. Comparación de la facturación de cada producto con el promedio por producto.

Al final del archivo se incluyen tres hallazgos obtenidos del análisis.

Para utilizar estas consultas, primero se debe crear y cargar la base de datos con el archivo `ventas_tech_db.sql`. Luego, ejecutar las consultas del módulo 4 sobre la base `Ventas_tech_DB`.

**Nota:** el script de creación elimina las tablas existentes antes de recrearlas. Utilizar únicamente en una base de práctica.
